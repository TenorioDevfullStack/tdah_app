# Contribuindo com o TDAH App

Obrigado por dedicar tempo para melhorar este projeto! Siga as orientações abaixo para manter um processo colaborativo organizado.

## Fluxo de trabalho

1. Abra uma issue descrevendo a motivação da mudança ou selecione uma existente.
2. Crie uma branch a partir de `main` seguindo o padrão `tipo/descricao-curta` (ex.: `feature/onboarding`).
3. Faça commits pequenos e descritivos. Utilize mensagens no formato imperativo (ex.: "Adiciona tela de onboarding").
4. Abra um pull request relacionando a issue correspondente e descreva claramente o que foi feito.
5. Solicite revisão de pelo menos uma pessoa do time.

## Padrões de código

- Consulte `docs/architecture.md` para garantir que novas implementações sigam as decisões arquiteturais.
- Execute os linters e testes automatizados definidos em `docs/development.md` antes de enviar o PR.
- Atualize a documentação sempre que necessário.

## Testes

- Inclua ou atualize testes unitários e de integração relevantes.
- Para mudanças visuais, forneça capturas de tela ou gravações.

## Comunicação

- Utilize a issue para alinhamentos e decisões.
- Para dúvidas urgentes, utilize os canais oficiais (Slack, Teams, etc.).

## Código de conduta

Ao contribuir, você concorda em seguir o `CODE_OF_CONDUCT.md`. Quaisquer violações devem ser comunicadas aos mantenedores.

Agradecemos sua contribuição!
